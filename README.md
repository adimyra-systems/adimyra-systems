## 🚀 What we do

- **ERPNext implementation & customization**: accounting, inventory, manufacturing, HR and more
- **Frappe Framework apps**: custom doctypes, workflows, integrations and the **adi-suite** modules
- **🦀 Rust engineering**: fast, memory-safe APIs, microservices, background workers and integration engines
- **PostgreSQL & MariaDB**: schema design, performance tuning, data migration and reporting
- **Headless ERP frontends**: React apps on top of Frappe / ERPNext and Rust backends
- **LIMS** for pathology labs, **e-commerce**, and custom software built around your workflows
- **GST & e-invoice** ready, **cloud & on-premise** deployment, **24/7 support**
